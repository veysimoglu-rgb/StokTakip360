# StokTakip360

Küçük ve orta ölçekli işletmeler için sade, hızlı ve mobil uyumlu stok takip uygulaması.

## Özellikler

- Ürün yönetimi
- Kategori yönetimi
- Marka yönetimi
- Cari hesap yönetimi (müşteri/tedarikçi tek hesap yapısında)
- Stok giriş/çıkış
- Stok hareketleri
- Değer raporları
- Kullanıcı/rol yönetimi
- Mobil/PWA desteği

## Teknoloji

- Laravel 12
- PHP 8.2+
- MySQL
- Blade
- Tailwind CSS
- Alpine.js
- Spatie Permission
